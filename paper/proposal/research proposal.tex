\begin{abstract}
Agents accumulate reusable skills while completing uncertain and sequential user tasks, however, evolving user demands can cause the skill library to be difficult to maintain. Refactoring reorganizes these components while retaining useful logic~\cite{skillsmith}.
However, decisions based only on current requests may lead to repeated revisions during migration or further architectural changes as new demands emerge, increasing cost and delaying task completion.

We propose SmartRefactorer, a frozen-LLM agent that forecasts plausible future demands to guide refactoring. It analyzes the repository and task history, forecasts the future user demands, selectively asks users when uncertainty is too large~\cite{voi}, and compares local development with alternative migration proposals~\cite{dsa}.

Our goal is to reduce frequent refactoring while maintain the quality of each refactoring, maintain a healthy skill-repository structure, and improve long-term efficiency under limited budgets and costs.

Evaluation will measure forecast reliability, its contribution to migration decisions, task success, capability preservation, cumulative tokens, and wall-clock time on verifiable task streams.
\end{abstract}
